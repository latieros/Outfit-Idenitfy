Where your photo goes

Unlike the other tools, this one sends the photo you pick to an AI model so it can read the outfit. On this site that's the provider you choose above, using your API key, which stays in this browser and goes only to that provider. Inside Claude it uses your Claude account instead. “Check tags” and character checks look the tags up on Danbooru. Calls with your own key are billed to that key's account.
