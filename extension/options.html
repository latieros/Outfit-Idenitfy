Outfit Tag Interpreter

  1. Right-click an image and choose Read outfit tags for a quick panel on the page.
  2. Choose Open in Outfit Tag Interpreter to get the full tool with catalog, variants and remix.
  3. Choose Add to outfit queue on up to 5 images, from any pages, then click the toolbar button to read them together.
  4. Right-click an empty spot and choose Read all outfits on this page to tag a whole gallery.

Stored in this browser's extension storage and sent only to api.anthropic.com.
