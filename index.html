About browser access and cost

The page calls the model API directly from your browser, so the key is sent only to that provider. Anthropic requires the anthropic-dangerous-direct-browser-access header for this; it's fine for a personal tool, but don't host this page publicly with a key baked in. Each image is downscaled to 1568px on its longest side before upload. Claude requests enable server-side refusal fallbacks by default.
