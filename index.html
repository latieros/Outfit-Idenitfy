About browser access and cost

The page calls the model API directly from your browser, so the key is sent only to that provider. Anthropic requires the anthropic-dangerous-direct-browser-access header for this; fine for a personal tool, but don't host this page publicly with a key baked in. Images are downscaled to 1568px before upload. Claude requests enable server-side refusal fallbacks.
