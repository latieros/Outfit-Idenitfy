How this works

The page asks Claude through your own claude.ai account, so there is no API key to paste. The first run asks you to allow it, and the dialog notes that the page sends images to Claude. Images are downscaled before upload. Identical repeat runs within five minutes replay the cached answer; “Regenerate” forces a fresh read. Live Danbooru post counts are not available inside an artifact, so “Check tags” fixes spellings and marks vocabulary matches only.
